# MODA v0.2.0 quality study

Five deterministic seeds (3000..3004) were run at 30 dimensions with a population of 100, 1000 iterations, and an archive capacity of 100. GD, IGD, and two-objective hypervolume are normalized to each analytic front. ZDT3 uses only its five true nondominated intervals.
